# لؤلؤ العربية

## الأَولى في اللغات العالمي، الكوني، والحسابي

### لغة اللؤلؤ واللؤلؤة

> مش قصتنا نعدّ الحروف؛ قصتنا نتعلّم نشوف شو بتقدر الحروف تعمل.

كتاب بحثي بالعربي المحكي، وأطلس تفاعلي، وسجلّ لآلئ قابل للمراجعة، عن **حروف صُفْر** (الحروف الافتتاحية في ٢٩ سورة) وعن هندسة الحروف في النص القرآني. المؤلف: **عبد قعدان** (Abed Kadaan). جزء من سلسلة «لؤلؤ الصُّفْر وهندسة الحروف».

*The Pearls of Arabic — al-Awlā among the Languages: Global, Cosmic, and Computational. A research book in colloquial Levantine Arabic, an interactive atlas, and an auditable registry of findings ("pearls") about the Qur'anic opening letters (al-ḥurūf al-muqaṭṭaʿa), which this project calls* ḥurūf ṣufr *(cipher letters). Every Qur'anic quotation is pulled from the verbatim Tanzil text at build time; nothing is hand-typed.*

**العنوان أطروحة، مش نتيجة.** «الأَولى» بمعنى المؤلف: الأجدر والأحق بالاعتبار، مش «الأولى تاريخيًا». والكتاب كله اختبار أمين لهالأطروحة.

| سجلّ اللآلئ | `data/pearls.json` | كل لؤلؤة بهويتها وحالتها وطبقاتها الأربع (نص، قراءة، تفسير، نموذج) |

| الهوية | `data/brand.json` | العنوان وشعار «لغة اللؤلؤ واللؤلؤة» بمكان واحد |

| المنشأ | `PROVENANCE.md` | من وين إجت كل فكرة وشو صار فيها |
| المصطلحات | `TERMS.md` | المصطلحات المحفوظة وتعريفها |

## التشغيل

```sh
# Python ≥ 3.10، مكتبة قياسية بس، بلا أي تثبيت
python3 lab/build.py                       # تجارب + مواقع + لآلئ + فصول → web/
python3 -m unittest discover -s tests      # الثوابت
python3 -m http.server -d web 8080         # افتح http://localhost:8080
```

## حالة الأدلة (هلّق)

٢٥ لؤلؤة. الحالات: نص متحقَّق منه، بنية ملحوظة، قاعدة مصاغة، ظهر مثال مضاد، قراءة المؤلف، سؤال مفتوح، حقيقة قرائية. أبرز اللي طلع:

- **P-001/P-002** المواقع التسعة والعشرون مطابقة حرفيًا للنص (٣٠ وحدة؛ الشورى: حم ٤٢:١ وعسق ٤٢:٢ آيتان).
- **P-004** كل الحروف المغوصة الثمانية جوّا آية أطول؛ بس القاعدة «مغوص ⇔ جوّا آية» بتنكسر عند ق ون (١٧/١٩)، وتعديلها بينكسر عند ص (١٨/١٩). **ظهر مثال مضاد.**
- **P-005** المر وحدة من أقصر سلسلتين بيجمعوا الم والر؛ التانية «الرم» غايبة عن النص.
- **P-007/P-008** «لله الأمر» بتظهر مرتين بس: الرعد ١٣:٣١ والروم ٣٠:٤. وخط الأساس طلّع «يريكم البرق خوفا» مشتركة بين نفس السورتين.
- **P-015/P-016** «صرح» بثلاث آيات بس، كلها بسور النجوم (بس احتمالها ≈ ٨٫٥٪، مش نادرة). وفصلت، اللي بعد غافر مباشرة، هي الوحيدة بكوكبة حم فيها «سبع سماوات … أمرها».
- **P-024** مصطلح «جمالة الصفر» إله صدى حرفي بـ«كأنه جِمالتٌ صُفْر» (٧٧:٣٣) — بمعنى لون، مش شفرة.
- **P-025** هيكل «لولو» بثماني آيات، نفس الكلمة بالرسم: «لُؤْلُؤ» بست، و«لَوَلَّوْا» بثنتين (٩:٥٧، ٤٨:٢٢).

الثابت التحريري الأساسي (وفي اختبار إله): **م غاصت في المر في الرعد (١٣)، مش في الم في الروم (٣٠).**

## كيف تضيف لؤلؤة

١. أضف مدخل لـ`data/pearls.json` برقم جديد (`P-0NN`) وكل الحقول المطلوبة (شوف `schema` بأول الملف). المراجع القرآنية بتنكتب `[سورة، آية]` بس؛ **ما تكتب نص الآية باليد**.
٢. إذا اللؤلؤة إلها حساب، أضف دالة `expNN()` لـ`lab/experiments.py` وسجّلها بـ`EXPERIMENTS`.
٣. اختر الحالة بأمانة: ما بترفع حالة لؤلؤة لأنها حلوة أو لأنها بتوافق التوقع. وإذا لقيت مثال مضاد، اكتبه بـ`counterexamples`.
٤. شغّل `python3 lab/build.py` و`python3 -m unittest discover -s tests`.

## للأنظمة الذكية (AI systems)

- مصدر الحقيقة: `data/*.json` و`results/*.json`. الملف `web/data.js` مولَّد، لا تعدّله.
- النص القرآني: استعمل `lab/quran.py` (`load().verse(s, a)`)، وما تولّد نص آية من الذاكرة.
- الحالات (`status`) جزء من المعنى؛ لا تنقل «بنية ملحوظة» أو «قراءة المؤلف» كأنها «حقيقة».
- التصنيف «مغوصة/طائرة» تصنيف أولي من المؤلف؛ المواقع «غير المحسومة» ما بينصنّفوا بدونه.

## اللي لسه ما انعمل (بصراحة)

- الكتاب: ٤ فصول مكتوبة من الرحلة الكاملة (شوف `book/OUTLINE.md`).
- نسخة PDF، وتطبيق React Native، وروابط لآلئ دائمة (PURL): مخطط إلها، لسه ما انبنت.
- مراجع القراءات (الرَّوْم، نقل ورش) بدها رقم صفحة من طبعة محددة ومراجعة مختص.
- العدّ: كل الحسابات على العدّ الكوفي (حفص). العدّات التانية لسه ما انفحصت.
